Key Talking Points for Data Science & ML Interviews
  • Why Standard Accuracy Fails: Explain that with 99.8% legitimate transactions, predicting all negatives yields 99.8% accuracy but catches 0 frauds.
  • Precision vs Recall Tradeoff: In fraud detection, missing a fraud (False Negative) has high financial risk, whereas flagging a legit transaction (False Positive) introduces customer friction. Tuning the decision threshold optimizes this cost function.
  • Why Random Forest Outperformed Decision Trees: Single decision trees overfit the noisy PCA features; the ensemble's feature subsampling ($\sqrt{p}$) and bootstrapping reduced prediction variance significantly.
  • Class Balancing Strategies: Contrast Random Undersampling (faster, drops data) with SMOTE (synthetic minority oversampling) and cost-sensitive class weighting.
model_training.py (Python ML Pipeline) 
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import recall_score, precision_score, roc_auc_score
from imblearn.over_sampling import SMOTE

# 1. Load data
df = pd.read_csv('creditcard_sample.csv')
X = df.drop(columns=['Class', 'Time'])
y = df['Class']

# 2. Stratified train/test split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)

# 3. Handle class imbalance using SMOTE
smote = SMOTE(random_state=42)
X_train_res, y_train_res = smote.fit_resample(X_train, y_train)

# 4. Train Random Forest Classifier
rf = RandomForestClassifier(n_estimators=100, max_depth=8, random_state=42)
rf.fit(X_train_res, y_train_res)
preds = rf.predict(X_test)
print(f"Recall: {recall_score(y_test, preds):.4f}, Precision: {precision_score(y_test, preds):.4f}")
